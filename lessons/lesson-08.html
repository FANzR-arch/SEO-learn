第八课 · 阶段二 关键词与搜索意图

把词，分配给页面

关键词研究的最后一步，是把候选词变成一张网站规划图：哪些词能共用一页、哪些需求值得分开，以及已有页面能否承接。每页围绕一个主要任务，可以回答多个相关问题。这就是关键词映射，也是阶段二的收尾。

学完这一课，你能做什么
把相近查询按用户任务和 SERP 分组；判断复用、更新还是新增页面；写出包含 URL、词组、意图、页面类型、目标和主要行动的关键词地图。
1 关键词聚类

目的相同的词，共用一个页面

关键词聚类是把可由同一页面有效满足的查询分组。它们通常有相近任务和结果页，而不只是共用一个单词。

教学假设：若 resume chatbot 和 chatbot resume 的实际结果和用户任务都接近，就可以先考虑共用一页；字序不同本身不足以证明需求相同。若分别建两个几乎一样的页面：

  • /resume-chatbot 和 /chatbot-resume 内容会高度重复；
  • 它们可能分散链接、让系统难以判断合适页面；只有当这种重叠妨碍目标页表现时，才需要处理关键词内耗（也叫同类相食）。多个页面覆盖同一查询本身不等于错误或处罚。
快速判断两个词能不能共用一页
在相同地区、语言和设备下分别搜索，比较前列自然结果中的相同 URL、页面类型和主要任务。重合多是合并线索，重合少是进一步核查的线索；「前十里有 5 个相同」可作经验参考，不是 Google 规则或通用阈值。
2 相关性看「任务」

别看词里有哪些字，看用户在完成什么

最容易犯的错，是看到共同的单词就以为相关。下面三个词都含 chatbot 和 resume，但用户任务完全不同。假设你在做一个「把简历变成可提问 AI」的产品，试着把每个词归到对的页面，或排除掉：

3 合并还是拆分

三个问题，决定一页还是两页

手里的词该并成一页、还是拆成几页？不看词长得像不像，看这三个问题的答案是否相同：

1用户任务
他来干嘛

看案例、选方案还是创建？看同一页面是否能有重点地满足这些任务。

2理想页面
该给什么

检查实际结果中的指南、案例或产品页，以及各自需要的内容深度。

3主要行动
自然的下一步

CTA（行动号召）是看演示、下载还是创建？它帮助检查体验，不能单独决定拆页。

任务相近、结果重合、内容可完整满足 → 倾向合并；任务明显不同、理想内容各有重点 → 倾向拆分。同一页可以有主要和次要 CTA。先盘点已有页面，再决定更新或新增；拆分后用有帮助的内链说明关系。

4 关键词地图

研究的产出物：一页围绕一个主要任务

把判断落到纸面，就是关键词地图。每个页面一行，记录主要词组、意图、类型、目标和主要 CTA；它是可更新的规划，不是每个词都要建一页。下面按已给定的教学假设示范：

URL主要词组主要意图页面类型用户目标主 CTA
/interactive-resumeinteractive resume
interactive resume examples		信息 / 商业调查指南 + 案例理解互动简历形式，判断是否适合自己看示例 / 演示
/resume-chatbotresume chatbot
chatbot resume（待真实结果确认）		商业调查 / 交易产品 + Demo评估并创建可对话简历试用 / 创建

注意最后两列：页面目标 ≠ CTA。目标描述页面帮助用户理解或完成什么，CTA 是下一步的行动入口。两者应服务实际任务，而不是硬套某个按钮——

给用户适合当前任务的下一步
在这个教学场景里，看案例的人先得到可浏览的示例；评估可对话简历产品的人可以看演示，再选择试用。是否直接让他上传文件，还取决于信任、隐私说明和产品要求；行动设计不能只看关键词。

你刚刚走完的这条链路，就是关键词研究变成网站规划的全过程：
关键词 → 搜索意图 → 页面类型 → 页面目标 → CTA。

5 随堂自测

点一点、填一填，检查你会了没

动手实践 · 25 分钟

把研究表变成第一版页面地图

  1. 从前两课的候选词中选 8–12 个，先按主要任务聚成 3–5 组；至少对一组相近词比较真实 SERP，并记录重合的 URL。
  2. 盘点项目已有页面，为每组指定「复用 / 更新 / 新增 / 暂缓」。每个拟承接页面记录 URL、主要与相关词、意图、页面类型、用户目标、主要 CTA 和一条相关内链。
  3. 检查是否为字序或同义词重复建页，是否把明显不同的任务硬塞在一起；不确定的分组写明待验证证据。
验收：3–5 行可以执行的地图
每行能说清「谁来、完成什么、为什么由这页承接、下一步去哪」。提交一项合并或拆分理由及其 SERP 证据；地图是草稿，不要求此时上线新页或删除旧页。
本课要点
  • 关键词聚类：目的相同的词共用一页；字序不同不代表要分页；
  • 相关性看用户任务，不看词里有哪些字；
  • 合并 / 拆分重点看用户任务、SERP 与内容能否完整满足；CTA 是体验线索，不是硬性拆页规则；
  • 产出物是关键词地图：一页一个主要任务，可覆盖多个相关查询；先盘点并复用已有页面。
